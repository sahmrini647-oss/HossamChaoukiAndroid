تجهيز تطبيق HOSSAM CHAOUKI للحصول على APK عبر GitHub

هذا المشروع يحتوي على إعداد آلي لبناء ملف APK. لا تحتاج إلى تثبيت Android Studio،
لكن يلزمك حساب GitHub واتصال بالإنترنت لتنفيذ البناء على خوادم GitHub.

الخطوات:
1) افتح https://github.com وسجّل الدخول أو أنشئ حساباً.
2) أنشئ مستودعاً جديداً (New repository)، وسمّه مثلاً HossamChaoukiAndroid.
   اجعله Private إذا كنت تفضّل عدم نشر ملفات المشروع للعامة.
3) ارفع محتويات هذا المجلد إلى المستودع مع الحفاظ على المجلدات كما هي، بما فيها
   .github/workflows/build-apk.yml و app/src/main/... ثم اضغط Commit changes.
   ملاحظة: يجب رفع الملفات والمجلدات الداخلية، وليس ملف ZIP وحده.
4) افتح تبويب Actions داخل المستودع.
5) اختر Build Android APK ثم اضغط Run workflow ثم Run workflow.
   (إذا بدأ البناء تلقائياً بعد رفع الملفات، انتظر حتى ينتهي؛ لا يلزم تشغيله مرة أخرى.)
6) افتح عملية البناء الأخيرة. عندما تظهر علامة نجاح خضراء، انزل إلى Artifacts.
7) نزّل HOSSAM_CHAOUKI_APK.zip وافتحه؛ ستجد داخله app-debug.apk.
8) انقل app-debug.apk إلى هاتف Android وافتحه للتثبيت. قد يطلب الهاتف السماح
   بالتثبيت من هذا المصدر؛ لا تسمح بذلك إلا إذا كنت تثق بالملف الذي بنيته بنفسك.

إذا فشل البناء:
- افتح عملية البناء الحمراء في Actions واقرأ أول رسالة خطأ.
- تأكد أن الملفات رُفعت إلى جذر المستودع، وأن مجلد .github مخفي لكنه مرفوع.

معلومات:
- هذا بناء Debug للتجربة والتثبيت الشخصي، وليس إصداراً منشوراً على متجر Google Play.
- ملف APK لا يُنشأ على هذا الجهاز مباشرة؛ GitHub ينفّذ البناء ثم يتيح تنزيل الناتج.
