HOSSAM CHAOUKI — Calculateur d'âge Android

Le projet inclut un workflow GitHub Actions pour générer automatiquement un APK.
Consultez README_AR.txt pour les étapes détaillées en arabe.

Le workflow utilise Java 17, Gradle 8.9 et la tâche assembleDebug. Le fichier APK
sera publié comme artefact nommé HOSSAM_CHAOUKI_APK dans l'exécution GitHub Actions.
Ce projet n'a pas été compilé localement dans cet environnement.
